# 婚前辅导多表单（本地网页）

浏览器内填写婚前辅导问卷，支持丈夫/妻子双方填写、自动对照、JSON 导入导出。  
**数据只存在本机浏览器，不上云。**

## 在线访问

https://jialezhouxin.github.io/premarital-counseling-forms/

## 本地运行

```bash
cd web
python -m http.server 8765
```

打开：http://127.0.0.1:8765/

## 功能

- 多表单：评估、约谈、期待、原生家庭、沟通、夫妻角色、性观念
- 称呼可自定义（首页「称呼」或填写页顶部），对照与打印报告都显示名字
- 丈夫 / 妻子分身份填写；填写页「导出本表」只导出**你自己那一侧**，包内带身份标记
- 首页 / 对照页「导出本表」导出双方；首页「导出全部 JSON」导出全部表单
- 导出文件名带称呼与日期：`premarital-assessment-阿明-20260914.json`
- 单人包按标记归位导入，不会覆盖对方那一侧；若本机该侧已有别人署名，会先警告
- 量表/选择题自动色标对照（绿一致 / 黄差1 / 红差≥2），单侧未答标「未齐」
- 对照页可筛「仅差异」「仅红」「仅未齐」，打印报告默认按当前筛选
- 单表或全部 JSON 导入导出；双机默认按人合并

## 双机流程（各填各的，最后合并）

1. 双方各自打开站点，先在两处「称呼」里填上真名
2. 各自点「填 · 自己」填完
3. 填写页「导出本表」→ 把 JSON 发给对方（或只发一份给汇总人）
4. 汇总人在首页用「导入 JSON」（全部包）或每张表的「导入本表」
5. 对照页「打印报告」→ 浏览器另存 PDF 给牧师

> PDF 需**每张表各打印一次**（一张表一份报告）；一键合并全表的汇总报告尚未实现。

## 目录

| 路径 | 说明 |
|---|---|
| `web/` | 静态站点（GitHub Pages 发布目录） |
| `scripts/` | 题库生成与导入导出测试 |
| `docs/` | 设计规格与实现计划 |

空白 Markdown 模板见仓库根目录 `*.md`（不含已填个人信息的 Word 原件）。


## 安装为 App（PWA）

- **Android Chrome**：打开站点 → 菜单 →「安装应用」或「添加到主屏幕」
- **iPhone Safari**：分享 →「添加到主屏幕」
- 首次需联网加载并缓存；之后可离线打开填写（答案仍在本机）
- 双机合并仍用 JSON 导出/导入（或隔空投送文件）


## 离线单文件包

- 文件：`web/premarital-counseling-offline.html`（也可在站点首页点「下载离线单文件」）
- 用法：把该 HTML 发给朋友 / 存到手机 → **直接用浏览器打开**，无需服务器、无需联网
- 重建：`python scripts/build_offline_html.py`（输出 `dist/` 并请复制到 `web/`）
- 答案仍在本机；双机对照继续用 JSON 导入导出


## 牧者打印报告

1. 双方填完并导入到同一浏览器  
2. 打开对应表单的 **对照** 页  
3. 可选筛选 **仅差异**（默认）/「仅红」/「全部已填」/「仅未齐」  
4. 勾选是否 **打印含开放题**、**打印含未答题清单**  
5. 点 **打印报告** → 浏览器打印/另存 PDF
